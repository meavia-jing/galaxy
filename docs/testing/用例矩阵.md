## 1 列定义

| 列 | 含义 |
| --- | --- |
| 用例 ID | 层级前缀 + 模块 + 序号。`UNIT` 单元、`INT` 集成、`SMK` 冒烟、`E2E` UI 自动化 |
| 任务 ID | 对应《迭代计划文档》的任务编号，保证每条用例都能追溯到验收清单 |

## 9 维护规则

1. 新增功能必须同时提交：实现 + 至少 1 条集成用例 + 矩阵对应行。
2. 用例 ID 一经分配不复用；删除用例时在矩阵标注「已废弃」并注明原因。
3. `docstring` 首行格式固定为 `[用例ID][任务ID] 验证点`，便于脚本抽取与 REG-META-01 校验。
4. 每次门禁执行后在矩阵「状态」列更新最近一次结果（通过 / 失败 / 跳过）。
5. 用例与验收清单冲突时，以《迭代计划文档》为准，矩阵随计划变更同步修订。
