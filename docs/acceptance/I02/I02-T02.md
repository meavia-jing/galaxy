## 实现要点

| 要求 | 落地位置 |
| --- | --- |
| access 只放内存，refresh 走 HttpOnly Cookie（`path=/api/v1/auth/`） | `accounts/views.py::_set_refresh_cookie`、前端 `stores/auth.ts` 只用 `access` |
| 刷新即旋转 + 旧 refresh 进黑名单 | `SIMPLE_JWT.ROTATE_REFRESH_TOKENS=True`、`BLACKLIST_AFTER_ROTATION=True`、`RefreshView` 显式 `old.blacklist()` |
| Cookie 认证必须带 CSRF 头 | `views.py::_require_csrf`（refresh/logout 逐请求校验头与 Cookie 一致） |
| 退出 / 改密 / 重置 / 禁用后旧令牌全部失效 | 令牌内嵌 `auth_version`；`User.bump_auth_version()`、`ChangePasswordView`、Admin reset 均 `auth_version+1`；`common/authentication.py` 每次请求回查数据库比对 |
| 并发 401 只触发一次刷新 | 前端 `api/http.ts::refreshAccessToken` 单飞 Promise |
