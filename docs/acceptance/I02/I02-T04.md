## 接口

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/v1/addresses/` | 仅返回本人地址，默认地址排在最前 |
| POST | `/api/v1/addresses/` | 新建；首个地址自动设为默认 |
| PATCH | `/api/v1/addresses/{id}/` | 局部更新；`is_default=true` 时互斥切换 |
| DELETE | `/api/v1/addresses/{id}/` | 删除；若删的是默认地址则自动提升一条 |

## 实现要点

- **归属隔离**：`get_queryset()` 固定 `filter(user=request.user)`，他人地址一律 404；
  `user` 字段不在序列化器字段内，请求体伪造 `user` 无效。
- **默认唯一**：`select_for_update()` 锁定用户行后再改 `is_default`，
  并发切换默认地址仍只会留下一个默认项（MySQL/MariaDB 无部分唯一索引）。
- **删除与快照**：地址物理删除；订单创建时写入 `Order.address_snapshot`，
  因此删除地址不影响历史订单（订单模型将在 I04 落地）。
- **不允许清空唯一默认**：仅有一个地址时 `is_default=false` 会被忽略。
- **上限**：每用户最多 20 个地址，超出返回 `ADDRESS_LIMIT`。
- **校验**：手机号或固话正则；收件人/省/市/区/详址去空格后不得为空。
