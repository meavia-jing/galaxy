## 后台人工重置（本批次新增）

| 项 | 实现 |
| --- | --- |
| 模型 | `accounts.AuditLog`：`actor` / `action` / `resource_type` / `resource_id` / `request_id` / `changes(JSON)` / `created_at`，`(actor, created_at)` 索引，`db_table=accounts_audit_log` |
| 只追加 | `AuditLogAdmin` 关闭增/改/删权限，仅保留查看；`date_hierarchy` 便于按日审计 |
| 重置动作 | `UserAdmin.actions = ("reset_password",)`：`secrets.token_urlsafe(12)` 生成临时密码 → `set_password` → `must_change_password=True` → `auth_version+1` → 写审计 |
| 审计脱敏 | `changes` 中密码记为 `***`，记录 `must_change_password` 与 `auth_version` 的 from/to；明文临时密码只出现在 Admin 的一次性提示消息里，不入库、不入日志 |
| 强制改密门禁 | `common/authentication.py`：`must_change_password=True` 时仅放行 `GET /api/v1/users/me/` 与 `POST /api/v1/users/me/change-password/`，其余返回 403 `FORBIDDEN`；改密成功后清除标记 |
| 前端配合 | `/account?force=1` 或资料里 `must_change_password=true` 时隐藏资料编辑区，只显示提示与改密表单 + 退出 |
| 多设备失效 | `auth_version+1` 使旧 access 立即 401、旧 refresh 刷新 401 |
