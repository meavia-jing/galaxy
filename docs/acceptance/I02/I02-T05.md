### 本批次新增的改密与强制改密（补齐个人中心）

| 行为 | 断言 |
| --- | --- |
| 两次新密码不一致 → 前端拦截、不发请求 | `UNIT-FE-23`：`apiPost` 未被调用，页面提示「两次输入的新密码不一致」 |
| 服务端 `fields.old_password` 回填 | `UNIT-FE-24`：显示「原密码不正确」 |
| `must_change_password` / `?force=1` → 隐藏资料区 | `UNIT-FE-25`：出现「管理员已重置你的密码」，资料输入框不存在 |
| 改密成功 → 换新 access、恢复资料区 | `UNIT-FE-25`：`setAccessToken('new-access')`，提示「密码已修改，其他设备已下线」，资料输入框回归 |
| 退出 → 清空 store 并回首页 | `UNIT-FE-26` |

浏览器实测（2026-11-15，Chrome，`127.0.0.1:5173`）：新增 → 设默认 → 编辑 → 删除全链路通过；删除需 `confirm`；后端 400 字段错误只出现在对应输入框下方且表单不关闭；390 px 无横向滚动。
