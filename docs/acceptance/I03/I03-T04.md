## 富文本净化（本批次新增）

| 项 | 实现 |
| --- | --- |
| 净化函数 | `backend/common/sanitizer.py::sanitize_html`，标准库 `html.parser` 实现，**不引入第三方依赖**（`bleach` 已停维护、`nh3` 需额外二进制，离线部署机多一个安装风险） |
| 标签白名单 | 排版语义标签：`p br hr span div strong b em i u s small sub sup ul ol li blockquote code pre h2~h6 a img table thead tbody tr th td` |
| 危险标签 | `script style iframe object embed svg math form input select textarea button head` 等**连内容一起丢弃**（只去标签会把脚本源码当正文显示） |
| 白名单外标签 | 去标签、**保留文本**（排版降级但不丢内容），如 `<font>`、`<marquee>` |
| 属性白名单 | `a`: `href title`；`img`: `src alt width height`；`td/th`: `colspan rowspan`。事件属性（`onerror`/`onclick`）一律不保留 |
| URL 协议 | `a` 仅 `http`/`https`/`mailto`；`img` 仅 `http`/`https`；无协议只放行 `/`、`#`、`?` 与字母数字开头的相对路径 |
| 绕过防护 | 先剔除 URL 内全部空白与控制字符再判协议，`java\nscript:`、`JAVASCRIPT:`、`jav&#x61;script:` 均被拦；`data:` 与协议相对地址 `//evil` 一并拒绝 |
| 外链加固 | 所有 `<a>` 强制追加 `rel="noopener noreferrer"` |
| 结构合法 | 未闭合标签由净化器补齐；交叉嵌套按最近同名标签闭合，输出不会是 `<b><i>x</b></i>` |
| 长度上限 | 正文超过 `MAX_BODY_LENGTH=50 000` 字符截断，避免超长载荷拖慢解析 |
| 写入收口 | `ContentPage.save()` 内统一净化：Admin、shell、脚本、将来的 API 都过同一函数 |
| 读取兜底 | `ContentPageSerializer.to_representation` 再净化一次，净化上线前的历史行即便仍是原始 HTML，公开接口也不会吐可执行片段 |
| 历史数据 | 数据迁移 `cms.0002` 把已入库正文批量净化一遍（`update()` 绕过 `save()`，不与历史模型纠缠） |

| `UNIT-SEC-10` | 空输入 | `None` / `""` → `""` |
| `UNIT-SEC-11` | 空属性值 | `href=""` 直接丢弃，不留空壳 |
| `UNIT-SEC-12` | 嵌套同名危险标签 | `<script><script>…` 按深度计数，不提前退出丢弃态 |
| `UNIT-SEC-13` | 注释/声明/处理指令 | 注释、`<!DOCTYPE>`、`<?php ?>` 整体丢弃 |

## 真机实况（开发库 + 运行中的服务）

```text
PS> python manage.py shell -c "... update(body='<p>正常段落</p><script>alert(document.cookie)</script><img src=x onerror=alert(1)><a href=\"javascript:alert(1)\">点我</a>') ..."
DB_RAW:    <p>正常段落</p><script>alert(document.cookie)</script><img src=x onerror=alert(1)><a href="javascript:alert(1)">点我</a>
SANITIZED: <p>正常段落</p><img src="x"><a rel="noopener noreferrer">点我</a>

PS> Invoke-WebRequest http://127.0.0.1:8000/api/v1/pages/xss-demo/
HTTP 200
{"data":{"slug":"xss-demo","title":"XSS 验证页","body":"<p>正常段落</p><img src=\"x\"><a rel=\"noopener noreferrer\">点我</a>","published_at":null},...}
```

即：**库里还是原始攻击载荷，公开接口已经吐不出可执行片段**（读侧兜底生效）。该验证页 `slug=xss-demo` 可用 `ContentPage.objects.filter(slug="xss-demo").delete()` 清除。

## 已知问题

1. 净化只覆盖 CMS 内容页正文。若后续给商品描述、评价内容加富文本（I08），必须复用 `sanitize_html`，禁止各处自己写正则。
2. Markdown 风格输入不会转换成 HTML，只在已有 HTML 上做白名单过滤；目前后台录的是 HTML，若将来支持 Markdown 需另加渲染步骤并在渲染后再净化一次。
3. 表格属性只放行 `colspan` / `rowspan`，`style` 一律丢弃，因此后台粘贴带内联样式的表格会丢配色（内容不丢）。
