## 5 五个容易踩的坑（上次踩过，别重踩）

1. **`wsl -e bash -lc` 里的引号**：PowerShell 不认 `\"` 转义，多行脚本先写到 `%TEMP%` 再 `bash /mnt/c/...` 执行，否则命令会被拆散。
2. **部署脚本要 LF 换行**：从 Windows 侧新建的 `deploy/*.sh` 是 CRLF，直接跑会报 `bad interpreter`。执行前 `sed -i 's/\r$//' deploy/*.sh`。
3. **`systemctl reload nginx` 是异步的**：reload 后立刻 curl 可能打到旧配置（曾误报 301）。健康检查必须带重试。
4. **空库的备份演练毫无意义**：第一次演练四张表行数全是 0，「恢复成功」什么都没证明。演练前先确认源库非空（`SELECT COUNT(*)`）。
5. **安装到仓库根的 pip 包会让 SMK-14 失败**：`markdown` 的 1066 行文件被计入行数检查。临时依赖必须装到 `%TEMP%` 之外仓库。
